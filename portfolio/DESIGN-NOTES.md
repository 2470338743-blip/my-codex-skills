# 设计与验证

采用 taste-skill 的 **The split stage**，seed **4403**。五张既有的蓝橙、薄荷绿海报成为一块可切换的画廊展示面；鼠标经过或键盘聚焦项目会切换左侧大图，点击后可放大并下载原图。平板和手机上，每张作品在正文中展开。

保留作品自身的色彩，以中性纸白和深绿承托。字体使用随包提供的 Noto Serif CJK 子集：原方向的 EB Garamond 在环境中不可用，且需要覆盖中文。联系区从照片条改为作品、短句与链接，因为没有订阅服务与十张以上照片。没有引入库存图片、外部视频或绘制假作品。

最终设计自评：设计 8.0、易用性 7.5、创意 7.0、内容 7.5，按 40/30/20/10 加权为 **7.6/10**。这是设计自评，不是外部评审。局限：尚无真实展示名、履历与邮箱，创作说明需要本人确认；作品以海报为主，未来应加入实际项目过程与结果。

验证：

- taste-skill 源码检查：0 FAIL、0 WARN。
- Chromium 渲染检查：1440、768、390 像素宽度，0 FAIL；图片、字体正常，无横向溢出，标题不超过两行。
- 唯一保留 WARN：没有视频。现有内容是静态印刷海报，没有真实过程视频；页面以轻微作品位移和分段进入呈现动态，不引入无关视频。
- 80 项浏览器断言通过：1440、768、390、320 宽度下的预览选择、大图与下载目标、Escape 关闭、焦点返回和键盘循环；无脚本回退、减少动态偏好、本地字体及运行时错误检查。
- 五张图片与来源文件逐字节相同。
- 管理策略禁止当前云端 Chromium 的 `file://` 导航；直接打开文件的验证被阻止。实际测试使用本地 HTTP 服务。没有修改该管理策略。
