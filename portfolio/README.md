# 视觉档案 · 个人作品集

使用 taste-skill 的 The split stage 方向（seed 4403）完成。桌面是固定作品预览与滚动阅读栏，平板与手机改为纵向作品展示。包含五张现有海报、创作说明、GitHub 链接、大图查看与原图下载。

## 使用

解压整个文件夹后打开 `index.html`。所有图片、字体和代码都在包内，无需 npm、API Key、构建工具或外部图床。

也可以在文件夹中运行 `python -m http.server 8000`，用浏览器访问该本地服务。此包尚未部署为公开网站。

## 修改个人信息

- 展示名：在 `index.html` 修改“视觉档案”、网页标题及页脚。
- 自我介绍：修改 `#about` 中的第一人称创作说明。这是根据当前作品拟定的文案，请在正式使用前确认。
- 联系方式：`#contact` 使用现有的 GitHub 个人页。尚未提供真实姓名、职业履历与邮箱，页面没有虚构这些资料。
- 新增作品：复制一个 `article.project`，给它唯一的 `id`，并保持其中链接的 `data-project` 与该 ID 相同。补充对应的预览按钮；脚本会自动读取作品标题、图片和分类。
- 字体：`assets/portfolio-serif.woff` 是 Noto Serif CJK 的当前文案子集。新增字符会使用系统衬线字体回退；需要全站严格一致时重新制作字体子集。原字体许可见 `assets/FONT-LICENSE.txt`。

## 内容来源

五张海报来自本次工作区的既有 AI 辅助创作成果，图片文件原样复制，未替换或改写。页面有明确的 AI 辅助创作说明。没有图库素材、虚构客户、奖项或项目数据。上传的原照片和待完成的胶带合成未放进网站。

## 验证说明

浏览器检查结果及设计自评见 `DESIGN-NOTES.md`。当前云端浏览器的管理策略禁止 `file://` 导航，直接打开本地 HTML 的检查受到该策略阻止；实际交互测试通过本地 HTTP 服务执行。页面不使用 fetch、ES modules 或路由服务等依赖服务器的功能。
